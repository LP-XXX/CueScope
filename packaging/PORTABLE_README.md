# CueScope Windows 便携版

在这个目录双击 `CueScope.exe` 即可打开。主程序、`_internal` 和 `capture-component` 需要保存在同一目录。使用本地记录和托盘提醒时无需提供远程通知凭据。

- [创建第一条提醒](QUICK_START.md)包括圈选窗口、建立基线和查看结果的步骤。快速入门中的下载链接指向 v0.3.0 候选版；启动程序时请使用当前解压目录内的 EXE。
- [兼容性与验证](VALIDATION.md)说明已知的现场验证范围。此包的构建标识、测试和组件自检摘要在 `validation/`。
- [代码许可证](LICENSE)和[第三方来源说明](THIRD_PARTY_NOTICES.md)列出分发条款。依赖许可证全文在 `licenses/`。

升级前从托盘退出并备份 `%LOCALAPPDATA%\DealWatch`。如需帮助，请附版本、目标应用、缩放比例和脱敏错误阶段。[发行历史](https://github.com/LP-XXX/CueScope/releases) · [报告问题](https://github.com/LP-XXX/CueScope/issues/new/choose)
