# 用 QQ 接收 CueScope 提醒

本页适用于 0.3.1 候选版本。已发布的 0.3.0 Windows 包支持本地与飞书。QQ 适配器的自动回归使用模拟接收端，真实账号权限和手机通知需要分别试发确认。

## 选择接收方式

| 方式 | 适用情况 | 谁会收到传出的内容 |
|---|---|---|
| PushPlus 简易绑定 | 希望使用既有推送服务，能够接受中转 | PushPlus 接收你选择外发的内容，然后转给绑定的 QQ |
| 腾讯直连 | 你有自己的 QQ 机器人，希望由本机直接发送 | 腾讯 QQ 机器人平台及绑定的 QQ 好友会话或群 |

打开**设置 → 通知**，选择“发送到已启用的接收端”并保存。打开“配置 QQ 与任务接收端”，添加目标，选择“发到我的 QQ”或“发到 QQ 群”。为每个目标起容易辨认的名称，例如“我的手机”或“值班群”。默认只发送通用提醒和事件短编号；勾选发送正文后，接收方可看到任务来源、命中词和识别文字。

### PushPlus 简易绑定

1. 在自己的 PushPlus 账户完成服务所需的认证，添加其 QQ 机器人并绑定个人会话。发到群时，把机器人加入目标群，允许主动消息，并在服务商控制台取得该群的配置编码。[服务商 QQ 绑定指引](https://www.pushplus.plus/doc/channel/qq.html)
2. 在 CueScope 选择“简易绑定 · 经 PushPlus”，填写用户 Token。发到群时还要填写群配置编码。普通档在 QQ 仅展示标题摘要，正文显示范围与额度取决于服务档位。
3. 如果需要核对后续转发结果，在服务商开启开放接口，并设置允许的出口 IP（按账号配置）。在 CueScope 的可选查询密钥栏填写该用户的 SecretKey。程序使用流水号查询结果。缺少查询权限时，记录会停在“中转已受理”，无需再次提交同一条消息。[服务商开放接口说明](https://www.pushplus.plus/doc/guide/openApi.html)

### 腾讯官方直连

1. 在 QQ 开放平台创建自己的机器人，取得 AppID 和 AppSecret，选择 WebSocket 事件接入；在对应会话范围开启单聊消息或群 @ 机器人消息。将机器人添加为好友或加入目标群，允许它主动发送消息。[腾讯接入指南](https://bot.q.qq.com/wiki/)
2. 在 CueScope 选择“直连腾讯 · 自有机器人”，填写凭据，点击“生成一次性绑定码”。按界面提示，在两分钟内私聊机器人发送完整绑定码，或在指定群 @机器人并发送绑定码。
3. 确认会话匹配后保存。程序由绑定事件取得该机器人的会话标识，私聊和群需要分别绑定。账号能否公开使用、主动消息权限和速率均以腾讯对该机器人的设置为准。[腾讯消息收发说明](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)

## 试发与排查

在通知设置里选择已保存的试发接收端，点击“发送测试消息”。这一次点击会向真实接收端外发。打开目标会话检查是否可见，并单独核对手机通知设置。日常监测时，打开“活动记录”的通知详情，能逐个查看接收端状态。

| 现象 | 可以检查什么 |
|---|---|
| 没有提醒事件 | 查看识别记录中的原文、基线、规则结果及去重状态 |
| 只有本地记录 | 检查全局外发开关、任务指定的接收端、免打扰时段 |
| 中转已受理 | 中转服务已给出流水号。确认查询密钥和开放接口权限，并查看服务商记录 |
| 拒收或限流 | 检查机器人主动消息开关、接收关系及服务商额度 |
| 结果未知 | 先到目标会话核对。超时可能发生在对方接受请求之后 |

接收端凭据由当前 Windows 用户的 DPAPI 加密保存。报告问题时可以提供平台名称、错误码、软件版本和合成复现步骤。请勿上传 Token、AppSecret、会话绑定码、个人消息或完整日志。
