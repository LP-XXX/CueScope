# 产品路线图

已发布的 Windows x64 候选版为 **v0.3.0**。它支持本地托盘、识别记录和可选飞书机器人。下面列的是开发和验证顺序。[下载候选版](https://github.com/LP-XXX/CueScope/releases/tag/v0.3.0) · [当前兼容范围](../VALIDATION.md) · [GitHub 里程碑](https://github.com/LP-XXX/CueScope/milestones)

| 顺序 | 要解决的问题 | 验收方式 |
| --- | --- | --- |
| 0.3.1 候选源码 · 投递可靠性 | 提醒按目的地独立排队，记录暂停、撤销、中转受理和最终回执。新收件端与新正文权限不会接手历史任务。 | 已覆盖模拟换群、撤销、分片、暂停和重启。 |
| 0.3.1 候选源码 · QQ 通知 | 自有腾讯机器人直连或经 PushPlus 绑定，默认只发摘要。[配置步骤](QQ-NOTIFICATIONS.md) | 已完成模拟回执和本机网关测试。真实账号、QQ 单聊、授权群和手机可见性待试发。 |
| 0.3.1 候选源码 · 日常使用 | 包内演示、新建任务直接填短语、原文及原因预览、独立任务维护、活动检索、免打扰和摘要。 | 已有合成回归。下一步收集新用户首次成功耗时和真实软件兼容反馈。 |
| 后续渠道 | 邮箱面向个人收件，企业微信面向内部协作群。 | 根据试用反馈和可用的授权试点安排版本。 |

有需求时，请写下“我想在哪个窗口看到什么变化，希望通知发到哪里”。这样的例子能帮助比较需求频率和实际成本。[提出使用场景](https://github.com/LP-XXX/CueScope/issues/new?template=feature.yml)
